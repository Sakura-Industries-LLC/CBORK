# Bundled RFC and Internet-Draft Text

This directory contains literal, unmodified copies of RFC and Internet-Draft text files used as references for this workspace.
The files are bundled for development, testing,
and documentation purposes and remain under the copyright and license terms applied to them by their original publishers.

## Layout

* `rfc/` - Standards-track and informational RFCs referenced by the CDDL tooling in this repository
* `related/` - Additional RFCs and Internet-Standard copies that are referenced indirectly

## Updating

Refresh bundled files only from their canonical IETF sources.
Do not edit the contents of these files; if local notes are needed, keep them in a separate file in the surrounding source tree.
