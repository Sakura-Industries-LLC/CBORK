# RFC Standard CDDL

This directory contains the standard CDDL files that are expected to be available by known name.

These files are sourced from the [`cabo/cddlc` repository data directory][cddlc-data].

Snapshot date: 21 May 2026.

The upstream material is MIT licensed, and this directory includes a local `LICENSE` file covering the copied data.

Keep filenames stable where possible so RFC references and include-name lookups remain obvious.

[cddlc-data]: https://github.com/cabo/cddlc/tree/master/data
