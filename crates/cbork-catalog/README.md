# cbork-catalog

Compiled catalog of well-known CDDL and CBOR names used across the CBORK workspace.

## Purpose

`cbork-catalog` is a build-time-generated, O(1)-lookup catalog of the standard-library CDDL module names from `cddl/rfc-std/`.
Its purpose is to let `cbork-cddl-compiler` resolve `import` / `include` directives and `known_names()` callers identify the modules
that ship with the tool without scanning the filesystem at runtime.

The catalog is regenerated by `build.rs` from the contents of `cddl/rfc-std/*.cddl` on every build;
the resulting `phf::Map` is `include!`-d into `src/lib.rs`.

## Usage

```rust
use cbork_catalog::{known_names, known_content};

assert!(known_names().contains(&"rfc8610"));
let cddl = known_content("rfc8610").expect("rfc8610 is in the catalog");
```

This crate is primarily used by `cbork-cddl-compiler`; the `cbork` CLI also exposes the catalog via internal diagnostics.
